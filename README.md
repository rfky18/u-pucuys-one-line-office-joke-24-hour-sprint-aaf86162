A deterministic Node program (standard library only) that writes one fixed one-line joke about office life — 117 characters — to `/output/entry.txt`.

> "I raised an IT ticket about my chair — it was closed as 'working as intended', and now my back has filed a grievance."

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes the joke with no trailing newline, then re-reads the file and verifies it byte-for-byte (strict 1–200 character check) before exiting.
